Common Exam Traps

Distinctions DP-600 loves to test

Direct Lake vs Import vs DirectQuery

Import copies data in-memory at refresh (fast, latent). DirectQuery hits the source live (fresh, slower). Direct Lake reads Delta files in OneLake directly — Import speed + DirectQuery freshness, no refresh copy.

Lakehouse vs Warehouse

The lakehouse SQL analytics endpoint is read-only T-SQL (views/funcs/procs + SELECT; modify via Spark). The warehouse gives full transactional T-SQL DML (INSERT/UPDATE/DELETE) with ACID.

Direct Lake on OneLake vs on SQL

Direct Lake on SQL can fall back to DirectQuery (RLS, views, guardrails). Direct Lake on OneLake does not fall back — exceeding guardrails fails refresh / errors queries, like Import.

Calculation group vs measure

A calculation group applies one set of items (YTD, MTD, PY…) to any selected measure via SELECTEDMEASURE(). Adding one switches all measures to the variant data type.

Deployment pipeline vs version control

Git integration = continuous integration (version, branch, PR). Deployment pipelines = continuous deployment (promote dev→test→prod). Deployment copies only metadata, not data.

Internal vs external shortcuts

Internal OneLake shortcuts authorize with the calling user's identity. External shortcuts (ADLS Gen2, S3) use a cloud connection with stored credentials. No data is copied either way.
