Common Exam Traps

Distinctions DP-700 loves to test

Dataflow Gen2 vs notebook vs pipeline

Dataflow Gen2 is low-code Power Query transform. Notebooks give code-first Spark (PySpark/SQL) for scale & complex logic. Pipelines orchestrate — they move and schedule activities, not transform row-by-row.

Lakehouse vs warehouse vs eventhouse

Lakehouse = Spark + Delta files, read-only SQL endpoint. Warehouse = full transactional T-SQL (DML, ACID). Eventhouse = KQL over high-volume real-time/streaming telemetry.

OneLake shortcuts vs mirroring

Shortcuts reference data in place — no copy, live pointer to ADLS/S3/OneLake. Mirroring replicates an external database (Azure SQL, Snowflake, Cosmos DB) into Fabric and keeps it in near-real-time sync.

Full vs incremental load

Full load truncates and reloads everything — simple, costly at scale. Incremental load moves only new/changed rows via a watermark or CDC, and must handle late-arriving and duplicate data.

Batch vs streaming ingest

Batch = pipelines / Dataflows / notebooks on a schedule. Streaming = Eventstreams or Spark structured streaming for continuous, low-latency data with windowing — land it in an eventhouse or lakehouse.

Deployment pipelines vs Git

Git integration = version control (branch, commit, PR) for source. Deployment pipelines = promote items dev→test→prod. Deployment copies item metadata between stages, not the underlying data.
