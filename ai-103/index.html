Common Exam Traps

Distinctions AI-103 loves to test

RAG vs fine-tuning

RAG grounds a model on external data at inference — fresh, cited, no retraining. Fine-tuning bakes behavior and style into weights. Reach for RAG when knowledge changes or must be attributable; fine-tune to shape format or tone.

LLM vs SLM model choice

Large models maximize reasoning and breadth at higher cost/latency. Small language models are cheaper, faster and edge-friendly for narrow, high-volume tasks. Match model size to task complexity, not habit.

Semantic vs hybrid vs vector search

Vector search matches by embedding similarity. Keyword catches exact terms. Hybrid fuses both, and semantic ranking re-scores results by meaning. Hybrid + semantic ranker is usually the strongest recall for RAG grounding.

Single-agent vs multi-agent orchestration

One agent with tools handles a bounded task. Multi-agent orchestration splits work across specialized agents (planner, researcher, critic) — more capable but more latency, cost and failure surface. Add agents only when the task decomposes.

Managed identity / keyless vs API keys

API keys are long-lived secrets that leak and rotate poorly. Managed identity with keyless auth uses Entra ID tokens + RBAC — no secret to store. Keyless is the recommended production default.

Content Understanding vs Document Intelligence

Document Intelligence targets structured OCR — layout, tables, prebuilt/custom fields. Azure AI Content Understanding is multimodal (documents, images, audio, video) with analyzer-driven schema extraction. Pick by modality and output shape.
