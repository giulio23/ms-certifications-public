Common Exam Traps

Distinctions AB-620 loves to test

Topic vs Agent flow

A topic is the conversational unit (trigger phrases, nodes, generative answers). An agent flow is an automation the agent calls to do work (actions, connectors, human-in-the-loop) — invoke it from a topic when you need logic or a system action.

Knowledge source vs Tool

A knowledge source grounds answers (SharePoint, website, Dataverse, Azure AI Search) — retrieval/RAG. A tool lets the agent take an action (MCP, REST API, connector action, computer use). Grounding ≠ acting.

Single vs Multi-agent (A2A)

Connect agents so one orchestrates others (child agents, a Foundry agent, a Fabric data agent). The A2A protocol standardizes agent-to-agent calls across platforms — reach for it when integrating an external/existing agent.

Generative answers vs Custom prompt

A generative answers node synthesizes a reply from knowledge sources at runtime. A custom prompt (optionally on a Foundry model) is an authored, reusable AI call with defined inputs/outputs used inside a topic or flow.

Managed vs Unmanaged solution

Author in an unmanaged solution (editable) in dev; deploy a managed solution to test/prod (locked, cleanly uninstallable). Power Platform Pipelines promote across environments; environment variables + connection references keep config portable.

Copilot vs Power Platform connector

A Copilot (graph) connector indexes enterprise content as a knowledge source. A Power Platform connector exposes an API as an action/tool. Same word, different jobs — grounding vs. calling out.
