Common Exam Traps

Distinctions AI-901 loves to test

Identify vs implement

D1 asks which AI workload fits a scenario (concept). D2 asks how to build it in Microsoft Foundry (SDK, portal, prompts). Read whether the question wants you to choose a capability or wire it up.

Responsible AI principles

Six principles: fairness, reliability & safety, privacy & security, inclusiveness, transparency, accountability. Common trap — inclusiveness (accessibility) vs fairness (unbiased results); transparency (explainability) vs accountability (human ownership).

Model parameters

Temperature / top-p control randomness; max tokens caps length. Lower temperature = more deterministic. Know what each parameter does and which to change for more focused vs more creative output.

System vs user prompt

The system prompt sets the assistant's role, rules and tone for the whole conversation. The user prompt is the specific request. Put persistent behavior in the system message, not repeated in every user turn.

Match the workload to the service

Speech → speech-to-text / text-to-speech / translation. Vision → interpret or generate images (multimodal). Extraction → Azure Content Understanding for documents, forms, images, audio & video. Pick by the input type.

Foundry portal vs SDK

The Foundry portal is where you deploy a model and test it interactively. The Foundry SDK (Python) builds a lightweight chat or agent client in code. Know which one a scenario points to.
