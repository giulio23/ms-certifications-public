Common Exam Traps

Distinctions PL-900 loves to test

Canvas vs model-driven apps

Canvas apps are pixel-first — design the exact UI and wire logic with Power Fx, great for task-focused apps on any data source. Model-driven apps are data-first — the Dataverse model drives forms, views and layout. Pick by whether UX or the data model leads.

Which service for the job?

Power Apps = build apps. Power Automate = automate workflows. Power Pages = external-facing websites. Dataverse = store data. Copilot Studio = build agents. Connectors = integrate. Match the need to the service.

Cloud vs desktop flows

Cloud flows run in the cloud on triggers/connectors (automated, instant, scheduled). Desktop flows are RPA — they automate the UI of legacy/desktop apps with no API. Use desktop flows only when there is no connector.

Trigger types

Automated fires on an event (a row is created, an email arrives). Instant runs on demand (a button). Scheduled runs on a recurrence. Match the trigger to what starts the process.

Dataverse vs a spreadsheet

Dataverse is a secure, relational cloud data platform — tables, columns, relationships, business rules, and role-based security — not just a list. It is the native store for model-driven apps and underpins the whole platform.

Connectors: standard vs premium

A connector is a proxy to an API used by apps and flows. Standard connectors come with base licensing; premium (e.g. Dataverse, SQL, custom/HTTP) need a premium plan. Know the trigger-vs-action distinction too.
