Common Exam Traps

Distinctions AB-100 loves to test

Build custom agent vs extend M365 Copilot

Extend M365 Copilot when the work lives inside the Microsoft 365 experience and needs your data/actions surfaced there. Build a custom agent (Copilot Studio / Foundry) when you need a standalone, purpose-built agent with its own channels, orchestration, and lifecycle.

Copilot Studio vs Microsoft Foundry

Copilot Studio is the low-code home for business agents (topics, flows, prompt actions). Microsoft Foundry is the pro-code platform for custom models and the Agents service. Pick by builder skill set and control needed, not by feature name alone.

NLP / CLU vs generative orchestration

Classic NLP and conversational language understanding match utterances to authored intents and topics — predictable, tightly scoped. Generative orchestration lets the model select topics, actions, and knowledge dynamically — flexible, but needs stronger grounding and testing.

Task vs autonomous vs prompt-and-response agents

Prompt-and-response agents answer a request in the moment. Task agents complete a defined multi-step job. Autonomous agents are triggered by events and act without a user in the loop — the highest-governance option.

When to use a model router

A model router picks the right model per request to balance cost, latency, and quality — reach for it when workloads are mixed. Don't hard-pin one premium model for every call; route cheap requests to smaller models and reserve the strong model for hard ones.

Grounding data quality vs prompt engineering

Hallucinations and wrong answers usually trace to weak, stale, or poorly scoped grounding data — not to prompt wording. Fix the knowledge sources, permissions, and freshness first; prompt tuning can't rescue bad grounding.
